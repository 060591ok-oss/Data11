# Моделі даних та інформаційні системи — інтерактивна сторінка

Файли: `index.html` (сторінка), `apps-script/Code.gs` (приймач результатів для Google Таблиці).

## 1. Публікація на GitHub Pages
1. Створіть репозиторій і завантажте `index.html` (папку `apps-script` можна теж).
2. Settings → Pages → Branch `main`, папка `/ (root)` → Save.

## 2. Збереження результатів у Google Таблиці (на Google Диску)
1. На Google Диску створіть нову Google Таблицю (назва довільна).
2. Розширення → Apps Script. Видаліть вміст і вставте код із `apps-script/Code.gs`. Збережіть.
3. Розгорнути → Нове розгортання → тип «Веб-застосунок».
   - Виконувати від імені: **я**
   - Хто має доступ: **усі**
4. Дозвольте доступ до таблиці, скопіюйте **URL веб-застосунку** (закінчується на `/exec`).
5. У `index.html` знайдіть рядок `const SCRIPT_URL = "";` і вставте URL між лапками. Завантажте оновлений файл на GitHub.

Результати з’являться на аркуші «Результати»: час, ім’я, клас, частина (Завдання/Тест), бали, відповіді.
Після зміни коду скрипта створіть нову версію розгортання (Розгорнути → Керувати розгортаннями → Редагувати → Нова версія).

## Про «одну спробу»
- У браузері учня спроба блокується (запам’ятовується в localStorage).
- На стороні таблиці повторний запис для тієї самої пари «ім’я + клас + частина» відхиляється.
- Якщо учень очистить дані браузера й введе те саме ім’я та клас, у таблиці лишиться лише перший результат.
- Правильні відповіді є в коді сторінки, тому дуже підкований учень може їх переглянути. Для суворого контролю оцінювання потрібно переносити на сервер.
